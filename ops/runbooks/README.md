# Runbook placeholders

Service runbooks will be added with deployable runtimes and must cover symptom,
alert, impact, diagnosis, mitigation, rollback/failover, verification, and
escalation. On-call assignments and tooling remain `TBD-020`.

The product-neutral on-call and approval interfaces are defined in
[`../coordination/`](../coordination/README.md). Concrete system bindings must
be published separately before production promotion.
